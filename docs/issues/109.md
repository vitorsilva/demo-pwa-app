# Issue #109: Hide 'Save quiz locally' button for host on results screen

**GitHub:** https://github.com/vitorsilva/saberloop/issues/109
**Status:** Open
**Created:** 2026-01-15
**Labels:** bug, party-mode
**Branch:** `fix/issue-109-hide-save-button-host`

---

## Problem

On the Party Mode results screen, the host sees a "Save quiz locally" button. This doesn't make sense because the host already has the quiz saved locally - otherwise they couldn't have started the party session in the first place.

## Expected Behavior

- **Host:** Should NOT see the "Save quiz locally" button (quiz already exists locally)
- **Guest:** Should see the button (they don't have the quiz yet)

## Current Behavior

Both host and guest see the "Save quiz locally" button.

## Acceptance Criteria

- [ ] Host does not see "Save quiz locally" button on party results screen
- [ ] Guest continues to see the button
- [ ] No regression in solo quiz results screen behavior

---

## Root Cause Analysis

**File:** `src/views/PartyResultsView.js` (lines 155-161)

The "Save quiz locally" button is rendered unconditionally for all participants:

```javascript
<button
  id="saveBtn"
  class="w-full py-3 rounded-xl border-2 border-primary text-primary font-medium
         hover:bg-primary/10 transition-colors"
>
  ${t('party.saveLocally')}
</button>
```

The `isHost` property is already available in the view (line 30) and is used to conditionally render the "Play Again" button (lines 143-153), but the save button lacks this conditional logic.

---

## Solution Design

### Approach

Wrap the "Save quiz locally" button with the same conditional rendering pattern already used for the "Play Again" button:

```javascript
// Current (line 143-153) - Play Again button (host only)
${this.isHost ? `
  <button id="playAgainBtn" ...>
    ${t('party.playAgain')}
  </button>
` : ''}

// Fix (line 155-161) - Save button (guest only)
${!this.isHost ? `
  <button id="saveBtn" ...>
    ${t('party.saveLocally')}
  </button>
` : ''}
```

### Files to Change

| File | Change |
|------|--------|
| `src/views/PartyResultsView.js` | Add conditional `${!this.isHost ? ... : ''}` wrapper around save button |

### i18n Impact

**None.** This change only hides an existing button - no new translation keys required. The existing key `party.saveLocally` remains unchanged.
