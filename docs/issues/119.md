# Issue #119: Fix TypeScript/JSDoc type annotation errors in CI

---

## Problem

GitHub Actions CI is reporting TypeScript type annotation errors on several files. These are pre-existing issues that need to be resolved.

---

## Affected Files

### src/main.js (line 252)
```
Property 'userAgent' does not exist on type 'never'.
```

### src/core/router.js (line 244)
```
This expression is not constructable.
```

### src/components/ModeToggle.js (line 56)
```
Property 'dataset' does not exist on type 'Element'.
```

### src/api/openrouter-client.js (lines 51, 52, 62, 71, 176)
```
Property 'status' does not exist on type 'Error'.
Property 'response' does not exist on type 'Error'.
```

---

## Root Cause

JSDoc type annotations are incomplete or incorrect, causing TypeScript strict mode checks to fail.

---

## Suggested Fixes

1. **main.js**: Add proper type narrowing for `navigator`
2. **router.js**: Fix ViewClass type definition to be constructable
3. **ModeToggle.js**: Cast `btn` to `HTMLElement` instead of `Element`
4. **openrouter-client.js**: Create a custom error type that includes `status` and `response` properties
