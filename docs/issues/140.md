## Problem

On the homepage, quizzes are not sorted by date with the most recently played at the top. Instead, older quizzes (e.g., from "last week") appear above more recent ones (e.g., from "today").

5. "Personagens, enredo..." - Ontem (yesterday) - 3/5

## Root Cause Analysis

### Root Cause: Data Type Inconsistency in Timestamps

The bug is caused by **inconsistent timestamp data types** across different parts of the codebase:

| Source File | Line | Timestamp Format | Example Value |
|-------------|------|------------------|---------------|
| `sample-loader.js` | 36 | Number (zero) | `0` |
| `quiz-import.js` | 66 | **ISO String** | `"2026-01-09T14:30:00.000Z"` |
| `ResultsView.js` | 229, 249 | Number (milliseconds) | `1737027000000` |

**The problematic code** is in `src/services/quiz-import.js:64-70`:

```javascript
const session = {
  ...quiz,
  timestamp: new Date().toISOString(),  // ← BUG: Should be Date.now()
  userAnswers: [],
  score: 0,
  totalQuestions: quiz.questions.length,
};
```

### Why `toISOString()` Was Used (Investigation Finding)

The original plan document (`docs/learning/epic06_sharing/PHASE1_QUIZ_SHARING.md:600,625`) specified `Date.now()` (numeric):

```javascript
quiz.importedAt = Date.now();
quiz.createdAt = Date.now();
```

However, the implementation in `quiz-import.js:66` used `new Date().toISOString()` instead. After reviewing:
- The Phase 1 learning notes (`PHASE1_LEARNING_NOTES.md`)
- All epic02 IndexedDB documentation (`PHASE2_INDEXEDDB.md`)
- Related code patterns

**Finding:** There is no documented reason for this deviation. The ISO string format was likely copied from logging/API response patterns (where it's appropriate for human readability) rather than following the IndexedDB storage patterns established in epic02.

This was an **implementation oversight**, not a deliberate design decision.

### Why This Causes Incorrect Sorting

IndexedDB sorts index keys by type in this order: **Numbers < Strings**

The retrieval flow:
```
getRecentSessions()
  → getAllFromIndex('sessions', 'byTimestamp')  // Ascending: numbers first, then strings
  → .reverse()                                   // Descending: strings first, then numbers
  → .slice(0, limit)
```

**Result after `.reverse()`:**
1. String timestamps (imported quizzes) appear FIRST regardless of actual date
2. Numeric timestamps (played quizzes) appear AFTER

This is why imported quizzes from "last week" appear above quizzes played "today".

### Data Flow Diagram

```
Imported Quiz (last week):
  saveImportedQuiz() → timestamp: "2026-01-09T..." (STRING)
                                     ↓
                        IndexedDB sorts strings AFTER numbers
                                     ↓
                        After reverse(): strings appear FIRST ❌

Played Quiz (today):
  ResultsView.saveQuizSession() → timestamp: 1737072000000 (NUMBER)
                                     ↓
                        IndexedDB sorts numbers BEFORE strings
                                     ↓
                        After reverse(): numbers appear AFTER strings ❌
```

## Solution

### Two-Part Fix

**Part 1: Fix the source of bad data** (`quiz-import.js`)

Change line 66 from:
```javascript
timestamp: new Date().toISOString(),
```
To:
```javascript
timestamp: Date.now(),
```

**Part 2: Make sorting robust** (`db.js`)

Change `getRecentSessions` to use explicit JavaScript sorting instead of relying on IndexedDB index ordering. This handles:
- Mixed data types (legacy string timestamps)
- Null/undefined timestamps
- Zero timestamps (samples)

```javascript
export async function getRecentSessions(limit = 10) {
  const db = await getDB();
  const all = await db.getAll('sessions');

  // Normalize and sort by timestamp descending (newest first)
  all.sort((a, b) => {
    const tsA = normalizeTimestamp(a.timestamp);
    const tsB = normalizeTimestamp(b.timestamp);
    return tsB - tsA;
  });

  return all.slice(0, limit);
}

/**
 * Normalize timestamp to numeric milliseconds.
 * Handles: numbers, ISO strings, null, undefined, 0
 */
function normalizeTimestamp(ts) {
  if (!ts) return 0;
  if (typeof ts === 'number') return ts;
  if (typeof ts === 'string') {
    const parsed = Date.parse(ts);
    return isNaN(parsed) ? 0 : parsed;
  }
  return 0;
}
```

### Why Both Parts Are Needed

1. **Part 1** prevents new bad data from being created
2. **Part 2** fixes sorting for existing data with string timestamps (no data migration needed)

### Unit Tests (Vitest)

Add to `src/core/db.test.js`:

```javascript
describe('getRecentSessions', () => {
  it('returns sessions sorted by timestamp descending (newest first)', async () => {
    const now = Date.now();
    await saveSession({ topic: 'Old Quiz', timestamp: now - 86400000 * 7 }); // 7 days ago
    await saveSession({ topic: 'Today Quiz', timestamp: now });
    await saveSession({ topic: 'Yesterday Quiz', timestamp: now - 86400000 }); // 1 day ago

    const sessions = await getRecentSessions(10);

    expect(sessions[0].topic).toBe('Today Quiz');
    expect(sessions[1].topic).toBe('Yesterday Quiz');
    expect(sessions[2].topic).toBe('Old Quiz');
  });

  it('handles sessions with null/zero timestamps', async () => {
    const now = Date.now();
    await saveSession({ topic: 'No Timestamp', timestamp: 0 });
    await saveSession({ topic: 'Recent', timestamp: now });

    const sessions = await getRecentSessions(10);

    expect(sessions[0].topic).toBe('Recent');
    expect(sessions[1].topic).toBe('No Timestamp');
  });

  it('handles mixed timestamp types (string ISO and number)', async () => {
    const now = Date.now();
    const lastWeekISO = new Date(now - 86400000 * 7).toISOString(); // String (legacy)

    await saveSession({ topic: 'Last Week Import', timestamp: lastWeekISO }); // String
    await saveSession({ topic: 'Today Played', timestamp: now }); // Number
    await saveSession({ topic: 'Yesterday Played', timestamp: now - 86400000 }); // Number

    const sessions = await getRecentSessions(10);

    // Should sort by actual date value, not data type
    expect(sessions[0].topic).toBe('Today Played');
    expect(sessions[1].topic).toBe('Yesterday Played');
    expect(sessions[2].topic).toBe('Last Week Import');
  });
});

describe('normalizeTimestamp', () => {
  it('returns number timestamps unchanged', () => {
    expect(normalizeTimestamp(1737072000000)).toBe(1737072000000);
  });

  it('converts ISO string to number', () => {
    const iso = '2026-01-16T12:00:00.000Z';
    expect(normalizeTimestamp(iso)).toBe(Date.parse(iso));
  });

  it('returns 0 for null/undefined', () => {
    expect(normalizeTimestamp(null)).toBe(0);
    expect(normalizeTimestamp(undefined)).toBe(0);
  });

  it('returns 0 for invalid strings', () => {
    expect(normalizeTimestamp('not-a-date')).toBe(0);
  });
});
```

### E2E Tests (Playwright)

Create `tests/e2e/homepage-sort-order.spec.js`:

```javascript
import { test, expect } from '@playwright/test';

test.describe('Homepage quiz sort order', () => {
  test('displays quizzes sorted by most recent first', async ({ page }) => {
    // Seed database with sessions having different timestamps
    await page.evaluate(() => {
      const now = Date.now();
      return Promise.all([
        window.db.saveSession({ topic: 'Old Quiz', timestamp: now - 86400000 * 7, totalQuestions: 5 }),
        window.db.saveSession({ topic: 'Today Quiz', timestamp: now, totalQuestions: 5, score: 4 }),
        window.db.saveSession({ topic: 'Yesterday Quiz', timestamp: now - 86400000, totalQuestions: 5, score: 3 }),
      ]);
    });

    await page.goto('/#/');

    const quizTopics = await page.locator('[data-testid="quiz-topic"]').allTextContents();

    expect(quizTopics[0]).toBe('Today Quiz');
    expect(quizTopics[1]).toBe('Yesterday Quiz');
    expect(quizTopics[2]).toBe('Old Quiz');
  });

  test('sorts imported quizzes (string timestamps) correctly with played quizzes', async ({ page }) => {
    const now = Date.now();
    const lastWeekISO = new Date(now - 86400000 * 7).toISOString();

    await page.evaluate((data) => {
      return Promise.all([
        window.db.saveSession({ topic: 'Imported Last Week', timestamp: data.lastWeekISO, totalQuestions: 5 }),
        window.db.saveSession({ topic: 'Played Today', timestamp: data.now, totalQuestions: 5, score: 5 }),
      ]);
    }, { now, lastWeekISO });

    await page.goto('/#/');

    const quizTopics = await page.locator('[data-testid="quiz-topic"]').allTextContents();

    expect(quizTopics[0]).toBe('Played Today');
    expect(quizTopics[1]).toBe('Imported Last Week');
  });
});
```
