# Issue #148: Preserve topic input when quiz generation fails

**GitHub:** https://github.com/vitorsilva/saberloop/issues/148
**Status:** Open
**Created:** 2026-01-19
**Labels:** enhancement, ux
**Branch:** `fix/issue-148-preserve-topic-input`

---

## Problem

When quiz generation fails (LLM error, API timeout, rate limit, etc.), the user is navigated back to the topic input page but their original text is lost. This means if they typed a detailed prompt like "this new amazing question for you to generate the quiz about quantum physics for beginners", they have to retype everything.

**User Impact:**
- Frustrating to retype long/detailed topic descriptions
- May lead to user abandonment after failure
- Especially painful on mobile where typing is slower

---

## Current Behavior

1. User enters text in the topic input textarea on `/topic-input`
2. User clicks "Generate" → navigates to `/loading`
3. Quiz generation fails (LLM error, network issue, rate limit, etc.)
4. User sees error alert, clicks OK
5. User is navigated back to `/topic-input`
6. **The textarea is empty - original input is lost**

## Expected Behavior

When returning to `/topic-input` after a failed generation attempt, the original topic text should be preserved in the textarea so users don't have to retype it.

---

## Technical Context

**Relevant files:**
- `src/views/TopicInputView.js` - Topic input page
- `src/views/LoadingView.js` - Loading page that handles errors (lines 200-243)
- `src/core/state.js` - Global state management

**Current flow:**
1. TopicInputView stores topic in state: `state.set('currentTopic', topic)` before navigating
2. LoadingView navigates back on error: `this.navigateTo('/topic-input')`
3. TopicInputView does NOT restore the topic from state when rendering

---

## Proposed Solution

In `TopicInputView.render()`, check if `state.get('currentTopic')` exists and pre-fill the textarea with that value. This is a simple fix since the topic is already being stored in state before navigation.

```javascript
// In TopicInputView.render()
const savedTopic = state.get('currentTopic') || '';
const savedGrade = state.get('currentGradeLevel') || 'intermediate';

// Pre-fill textarea
textarea.value = savedTopic;

// Pre-select grade level
gradeSelect.value = savedGrade;
```
