## Problem

When quiz generation fails (LLM error, API timeout, rate limit, etc.), the user is navigated back to the topic input page but their original text is lost. This means if they typed a detailed prompt like "this new amazing question for you to generate the quiz about quantum physics for beginners", they have to retype everything.

**User Impact:**
- Frustrating to retype long/detailed topic descriptions
- May lead to user abandonment after failure
- Especially painful on mobile where typing is slower

---

## Current Behavior

1. User enters text in the topic input textarea on `/topic-input`
2. User clicks "Generate" → navigates to `/loading`
3. Quiz generation fails (LLM error, network issue, rate limit, etc.)
4. User sees error alert, clicks OK
5. User is navigated back to `/topic-input`
6. **The textarea is empty - original input is lost**

## Expected Behavior

When returning to `/topic-input` after a failed generation attempt, the original topic text should be preserved in the textarea so users don't have to retype it.

---

## Technical Context

**Relevant files:**
- `src/views/TopicInputView.js` - Topic input page (lines 66-91)
- `src/views/LoadingView.js` - Loading page that handles errors (lines 235-243)
- `src/core/state.js` - Global state management
- `src/api/api.mock.js` - Mock API for testing

**Current flow:**
1. TopicInputView stores topic in state: `state.set('currentTopic', topic)` before navigating (line 87-88)
2. LoadingView navigates back on error: `this.navigateTo('/topic-input')` (line 241)
3. TopicInputView does NOT restore the topic from state when rendering

**Existing mechanism:**
- There's already a `prefilledTopic` mechanism for deep links (lines 72-76)
- We need to also check for `currentTopic` (from failed generation)
- Priority: `prefilledTopic` > `currentTopic` > empty

**State defaults (from state.js):**
- `currentTopic: null`
- `currentGradeLevel: 'middle school'`

---

## Proposed Solution

In `TopicInputView.attachListeners()`, after checking for `prefilledTopic`, also check for `currentTopic` and `currentGradeLevel` if not already set.

```javascript
// In TopicInputView.attachListeners()
const topicInput = this.querySelector('#topicInput');
const gradeLevelSelect = this.querySelector('#gradeLevelSelect');

// Check for prefilled topic from deep link (existing code)
const prefilledTopic = state.get('prefilledTopic');
if (prefilledTopic) {
  topicInput.value = prefilledTopic;
  state.set('prefilledTopic', null); // Clear after use
} else {
  // NEW: Restore from currentTopic if returning from failed generation
  const savedTopic = state.get('currentTopic');
  if (savedTopic) {
    topicInput.value = savedTopic;
  }
}

// NEW: Restore grade level selection
const savedGradeLevel = state.get('currentGradeLevel');
if (savedGradeLevel) {
  gradeLevelSelect.value = savedGradeLevel;
}
```
