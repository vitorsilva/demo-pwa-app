## Marketing Update Workflow

When a new feature ships:

1. **Identify Marketing Impact**
   - Is this feature user-facing?
   - Does it differentiate us from competitors?
   - Would users choose Saberloop because of this?

2. **Create Task Document**
   - Create `TASK{N}_{FEATURE}_UPDATE.md` in this folder
   - Reference relevant feature documentation
   - Define landing page and Play Store changes

3. **Execute Updates**
   - Capture/process screenshots
   - Update landing page
   - Update Play Store listing
   - Update `docs/product-info/playstore-listing-update.md`

4. **Track in This Epic**
   - Update EPIC12_MARKETING_PLAN.md task table
   - Create learning notes if significant learnings

## Principles

1. **Keep materials current** - Update within 2 weeks of feature launch
2. **Benefit-driven copy** - Focus on user value, not technical details
3. **Show, don't tell** - Screenshots > text descriptions
4. **Mobile first** - Most users are on mobile
5. **Reuse assets** - Leverage existing screenshots and tooling
